# 工場見学 音声ガイド（PWA）

iPadのホーム画面に追加して使う、オフライン対応の見学ガイドです。
近くのスポットが上に並び、ボタンを押すと説明文を読み上げます。

- **本体（このリポジトリ）**：汎用の仕組みだけ。工場名・座標・説明文は含みません
- **台本（JSONファイル）**：iPadの「ファイル」アプリに置いて読み込みます。ネットには置きません。暗号化もできます

---

## 1. GitHub Pages に置く（最初の1回）

1. GitHubで新しいリポジトリを作る（名前は工場名を避ける。例：`tour-guide`）
2. このフォルダの中身をすべてアップロード
   （`index.html` `style.css` `app.js` `sw.js` `manifest.webmanifest` `icons/` `vendor/` `sample/` `README.md`）
3. リポジトリの **Settings → Pages** で、Branch を `main`、フォルダを `/ (root)` にして保存
4. 数分待つと `https://＜ユーザー名＞.github.io/tour-guide/` で開けるようになります

> 公開されるのは汎用の本体とサンプル（架空データ）だけです。検索エンジンに載らないよう `noindex` を指定しています。

## 2. iPadに入れる（各iPadで1回）

1. iPadの **Safari** で上記URLを開く（モバイル回線でOK。社内ネットワークは不要）
2. 共有ボタン →「**ホーム画面に追加**」
3. ホーム画面のアイコンから一度起動する（ここでオフライン用に保存されます）
4. 機内モードにしてアイコンから起動し、動けば準備完了

**設定アプリで事前にやっておくこと**

- 設定 → アクセシビリティ → 読み上げコンテンツ → 声 → 日本語：高音質の声（拡張版など）をダウンロードしておくと聞き取りやすくなります
- 起動後、位置情報とカメラ（QR用）の許可ダイアログで「許可」を選ぶ

## 3. 台本を読み込む

- 起動画面またはメニューの「**読み込む**」から、JSONファイルを選びます
- AirDropで受け取ったファイルは「ファイル」→「ダウンロード」に入ります
- 暗号化ファイルの場合はパスフレーズを聞かれます
- 読み込んだ台本はiPad内に保存され、次回からは自動で開きます

**元のJSONファイルは必ず「ファイル」アプリに残しておいてください。**
iOSがWebアプリの保存データを消すことがまれにあり、その場合は読み込み直せば復旧します。

## 4. 台本を作る・直す（編集モード）

1. メニュー →「編集モードにする」→ PIN（初期値 `0000`）
2. 「ツアー設定」で **PINを必ず変更**し、構内図の画像（CAD図面の書き出しや航空写真のスクリーンショット）を選ぶ
3. 「＋ スポット追加」で、各スポットの名前・説明文を入力
4. **現地で「現在地で登録（10秒平均）」**を押して緯度経度を記録（屋外は空が開けた場所、屋内は窓際が有利）
5. 「地図上で位置を指定」で、構内図のどこにあるかをタップ
6. メニュー →「**書き出す**」で、JSONを「ファイル」アプリに保存したり、AirDropで他のiPadへ送ったりする

**現在地を構内図に表示するには**、「緯度経度」と「地図上の位置」の両方を登録したスポットが3か所以上必要です（できるだけ広く散らばった3点以上）。この3点から、緯度経度と図面の位置の対応関係を自動で計算します。

### 屋内のスポット

屋内はGPSが弱いので、次のどちらかで選びます。

- **QRコード**：中身を `TOUR:S03`（S03はスポットのID。編集画面に表示されます）にしたQRコードを作り、現場に掲示します。画面右上の「QR」で読み取ると、そのスポットが選ばれます
- **タップ**：地図のピンか一覧の項目をタップします

屋内のスポットでも、緯度経度は入口付近などで登録しておくと、距離順に並ぶときの目安になります。

## 5. 画面の動き

| 状況 | 動き |
|---|---|
| GPS精度がよい（初期値 ±50 m 以内） | いちばん近いスポットが大きく表示され、一覧は近い順 |
| GPS精度が悪い・屋内 | 番号順に、まだ見ていない次のスポットを表示 |
| QR・タップで選択 | 選んだスポットを表示（「近くを自動表示に戻す」で解除） |
| 再生中 | 全画面で、読み上げ中の文をハイライト。文をタップするとそこから読み直し |

自動で喋り出すことはありません。必ず人が再生ボタンを押します。

## 6. 台本ファイルの形式

```json
{
  "version": 1,
  "title": "第2工場 見学ツアー",
  "map": { "image": "data:image/jpeg;base64,...", "width": 2400, "height": 1500 },
  "spots": [
    {
      "id": "S01",
      "no": 1,
      "name": "受付・安全説明",
      "nameEn": "Reception",
      "text": "日本語の説明文。句点ごとに区切って読み上げます。",
      "textEn": "English text (optional).",
      "lat": 35.0000000,
      "lng": 137.0000000,
      "x": 230,
      "y": 545,
      "image": ""
    }
  ]
}
```

- `map` は省略できます（その場合はスポットの緯度経度から簡易マップを描きます）
- `x` `y` は構内図画像の上での画素位置です
- `image` はスポットの写真（データURL）で、説明中の背景に表示されます
- 暗号化ファイルの形式は `{"format":"tour-enc-v1", ...}` です（PBKDF2-SHA256 で鍵を作り、AES-GCM 256bit で暗号化。ブラウザ標準の Web Crypto API を使用）

## 7. 本体を更新したとき

`sw.js` の先頭にある `CACHE = 'tour-guide-v1'` の番号を上げてからアップロードします。
iPadでネットにつないだ状態でアプリを2回起動すると、新しい版に入れ替わります。

## 8. 注意点

- 位置情報・オフライン保存・暗号化はHTTPSでのみ動きます（GitHub PagesはHTTPSです）。`file://` で直接開いても動きません
- GPSが使えるのはCellularモデルのiPadです。Wi-Fiモデルは、Wi-Fiが無い場所では位置が取れません
- 画面の自動消灯防止（Wake Lock）は、iPadOSのバージョンによっては効きません。その場合は 設定 → 画面表示と明るさ → 自動ロック を「なし」にしてください
- 写真や構内図を入れるとファイルが大きくなります（アプリ側で縮小しています）
- サンプル台本の座標・内容は架空のものです
