# 工場見学 音声ガイド（PWA）

iPadのホーム画面に追加して使う、オフライン対応の見学ガイドです。
近くのスポットが上に並び、ボタンを押すと説明文を読み上げます。

- **本体（このリポジトリ）**：汎用の仕組みだけ。工場名・座標・説明文は含みません
- **台本（JSONファイル）**：iPadの「ファイル」アプリに置いて読み込みます。ネットには置きません。暗号化もできます

---

## 1. GitHub Pages に置く（最初の1回）

1. GitHubで新しいリポジトリを作る（名前は工場名を避ける。例：`tour-guide`）
2. このフォルダの中身をすべてアップロード
   （`index.html` `style.css` `app.js` `sw.js` `manifest.webmanifest` `icons/` `vendor/` `sample/` `README.md`）
3. リポジトリの **Settings → Pages** で、Branch を `main`、フォルダを `/ (root)` にして保存
4. 数分待つと `https://＜ユーザー名＞.github.io/tour-guide/` で開けるようになります

> 公開されるのは汎用の本体とサンプル（架空データ）だけです。検索エンジンに載らないよう `noindex` を指定しています。

## 2. iPadに入れる（各iPadで1回）

1. iPadの **Safari** で上記URLを開く（モバイル回線でOK。社内ネットワークは不要）
2. 共有ボタン →「**ホーム画面に追加**」
3. ホーム画面のアイコンから一度起動する（ここでオフライン用に保存されます）
4. 機内モードにしてアイコンから起動し、動けば準備完了

**設定アプリで事前にやっておくこと**

- 設定 → アクセシビリティ → 読み上げコンテンツ → 声 → 日本語：高音質の声（拡張版など）をダウンロードしておくと聞き取りやすくなります
- 起動後、位置情報とカメラ（QR用）の許可ダイアログで「許可」を選ぶ

## 3. 台本を読み込む

- 起動画面（台本が入っていないとき）の「台本ファイルを読み込む」、または起動画面の下の小さな「台本ファイルを読み込み直す」、見学中はメニューの「**読み込む**」から、JSONファイルを選びます
- AirDropで受け取ったファイルは「ファイル」→「ダウンロード」に入ります
- 暗号化ファイルの場合はパスフレーズを聞かれます
- 読み込んだ台本はiPad内に保存され、次回からは自動で開きます

**元のJSONファイルは必ず「ファイル」アプリに残しておいてください。**
iOSがWebアプリの保存データを消すことがまれにあり、その場合は読み込み直せば復旧します。

## 4. 台本を作る・直す（編集モード）

1. メニュー →「編集モードにする」→ PIN（初期値 `0000`）
2. 「ツアー設定」で **PINを必ず変更**し、構内図の画像（CAD図面の書き出しや航空写真のスクリーンショット）を選ぶ
3. 「＋ スポット追加」で、各スポットの名前・説明文を入力
4. **現地で「現在地で登録（10秒平均）」**を押して緯度経度を記録（屋外は空が開けた場所、屋内は窓際が有利）
5. 「地図上で位置を指定」で、構内図のどこにあるかをタップ
6. メニュー →「**書き出す**」で、JSONを「ファイル」アプリに保存したり、AirDropで他のiPadへ送ったりする

**鳥瞰図（斜めから撮った写真）も構内図に使えます。** 基準点が3〜4か所のときは「アフィン」方式で位置を決め、**5か所以上**になると、斜めの見え方に合わせた「射影変換」方式に自動で切り替わります（誤差が小さくなる場合だけ）。基準点には、スポットの位置のほか、ツアー設定の「**地図の基準点**」で登録した点が使われます。「＋ 基準点を追加」で、名前と緯度経度（地図アプリで場所を長押しして出る値をそのまま貼り付けられます）を入れ、写真の上で同じ場所をタップします。画像の中で位置がはっきり分かる場所（建物の角、煙突の根元など）を、できるだけ広く散らして選びます。4か所目からは、点ごとの誤差が出るので、入力ミスを見つけられます。編集モード中は、基準点が紫の十字で地図に出ます。地図の範囲から大きく外れた地点（遠くの発電所など）は、地図には描かれません。ツアー設定の画面で、いまの基準点の数と方式を確認できます。

**現在地を構内図に表示するには**、「緯度経度」と「地図上の位置」の両方を登録したスポットが3か所以上必要です（できるだけ広く散らばった3点以上）。この3点から、緯度経度と図面の位置の対応関係を自動で計算します。

### コース（回るスポットと順番を変える）

スポットの場所・座標・説明文は変えずに、見学のたびに「どのスポットを、どの順番で回るか」だけを切り替えられます。

1. メニュー →「編集モードにする」→「**コース編集**」
2. 初めてのときは「**＋ 新しいコース**」を押す（いまの全スポットをコピーしたコースができます）
3. コース名を直し、「↑」「↓」で順番を変え、使わないスポットは「外す」、入れたいスポットは「＋ 追加」で入れる
4. 見学の前に、**起動画面**（青い「準備中」の画面）でコースを選びます。コースは大きなタイルで並び、選んだコースは青い枠になります。下に「回る順番」が出て、画面の下の帯の「見学を開始」を押すと見学中の画面（オレンジの「見学中」）に変わります。見学中も、画面右上の「**コース：○○**」ボタンから切り替えられます

- 選んだコースのスポットだけが、地図・一覧・次のおすすめ・進捗に出ます。含まれないスポットは地図からも隠れます
- 画面の番号は、**コースの中の順番**（1, 2, 3…）で振り直されます
- コースを切り替えるときは、「見学済みの記録をリセットする」をチェックしておくと、前の見学のチェックが消えます
- QRコードの中身（`TOUR:S03` など）はスポットのIDなので、コースが変わっても貼り替える必要はありません。いまのコースに含まれないスポットのQRを読むと、その旨が表示されます
- コースは台本ファイルの中に入っています。変更したら「書き出す」で保存し、他のiPadにも渡してください
- **コースの削除：** 起動画面（見学中ならコース選択）のコース一覧で、各行の右にある「削除」を押します。台本に保存されたコースの削除は、編集モードでなければPINを確認します（スポット自体は消えません）。「自分で選んだコース」の削除はPIN不要です。「全スポット」は削除できません。削除したあと、他のiPadに反映するときは「書き出す」を使います

### 自分で選ぶ（その場でスポットと順番を決める）

決まったコースを使わずに、見学の直前にスポットを1つずつ選び、順番まで決められます。編集モード（PIN）は要りません。

1. **起動画面**の「**＋ 自分で選ぶ**」を押します（見学中なら、画面右上の「コース：○○」→ 一番下の「＋ 自分で選ぶ」）
2. 回りたいスポットを、**回る順にタップ**します（①②③…と番号が付く。もう一度タップすると外れる）
3. 選んだスポットは**上に集まって番号順に並び**、「↑」「↓」で行ごと動かして順番を入れ替えられます。選んでいないスポットは下にまとまります。「いまのコースから始める」で、今のコースを土台にすることもできます
4. 「**この順にする**」を押すと、そのコースに決まります。起動画面の「回る順番」で確認し、「見学を開始」を押してください

起動画面の「**このコースの順番を変える**」を使うと、いま選んでいるコースを土台にして、順番だけを入れ替えられます。

- 自分で選んだコースは、iPadに**1件だけ**記憶されます（台本ファイルは変わりません）。次に「自分で選ぶ」を開くと、前回の選択が入った状態で始まり、上書きできます
- 気に入った組み合わせは「**コースとして保存**」で、名前を付けて台本のコース一覧に追加できます。台本の内容が変わるため、編集モードでなければPINを聞かれます。保存したあとは、他のiPadに渡すために「書き出す」を使ってください

### 屋内のスポット

屋内はGPSが弱いので、次のどちらかで選びます。

- **QRコード**：中身を `TOUR:S03`（S03はスポットのID。編集画面に表示されます）にしたQRコードを作り、現場に掲示します。画面右上の「QR」で読み取ると、そのスポットが選ばれます
- **タップ**：地図のピンか一覧の項目をタップします

屋内のスポットでも、緯度経度は入口付近などで登録しておくと、距離順に並ぶときの目安になります。

## 5. 画面の動き

**見学中の左のパネルは、乗換案内のような縦のルート**です（右上の「フロー／地図」で、構内図の地図表示に切り替えられます）。

- 選んだコースのスポットが、回る順に上から並びます。見学済みは緑のチェック、いま選ばれている（いちばん近い）スポットはオレンジに光ります。左に「済」「次」「いま」の印が出ます
- スポットとスポットの間に、「徒歩 約○○ m」の区間が出ます（緯度経度が登録済みのとき）。通過した区間は緑、次へ向かう区間はオレンジ、先の区間は点線のグレーです
- 現在地は、スポットの間に水色の点で出ます（スポットから20 m以内のときは、そのスポットに印が付きます）
- カードを押すと、そのスポットが選ばれます。コースを切り替えると、ルートもその場で変わります
- 「地図」に切り替えると、構内図・現在地・ピンが見えます。選んだ表示は次回も覚えています

**画面の色：** 起動画面（準備中）は青系、見学中の画面はオレンジ系です。どちらの画面かは、色と、左上の「準備中」「見学中」の札で分かります。

**見学中のヘッダー：** 左から「＜ コース選択」「見学中」の札、いまのコース名（▾）、右に QR・言語・メニューだけです。ツアー名、見学済みの数（左のパネルの上に出ます）、GPSの精度は、ヘッダーには出しません。GPSは、取得中・精度が低い・使えないときだけ、ヘッダーに黄色や赤の表示が出ます。

**コース選択に戻る：** 見学中の画面の左上の「＜ コース選択」で、起動画面（コース選択）に戻れます。コース名を押すと、その場でコースを切り替えられます。コースを選び直して、もう一度「見学を開始」を押せます。

**ライト／ダーク：** 初期はダーク（黒ベース）です。起動画面の右上、またはメニューの「表示」で、ダーク（黒ベース）に切り替えられます。明るい場所はライト（iOSの標準のような明るい背景）、暗い場所はダークが見やすくなります。選んだ表示は次回も覚えています。構内図の画像は、どちらの表示でも同じ色で出るので、明るい色の図面がおすすめです。

## 6. 台本ファイルの形式

```json
{
  "version": 1,
  "title": "第2工場 見学ツアー",
  "map": { "image": "data:image/jpeg;base64,...", "width": 2400, "height": 1500 },
  "spots": [
    {
      "id": "S01",
      "no": 1,
      "name": "受付・安全説明",
      "nameEn": "Reception",
      "text": "日本語の説明文。句点ごとに区切って読み上げます。",
      "textEn": "English text (optional).",
      "lat": 35.0000000,
      "lng": 137.0000000,
      "x": 230,
      "y": 545,
      "image": ""
    }
  ]
}
```

- `travel`（任意）は移動の手段です。`"car"` にすると、見学中のルートの区間が「車 約N分・直線 約○ m」（10 km/h換算）で出ます。省略または `"walk"` のときは「徒歩 約○ m」です
- 英語版は、スポットの `nameEn`（名前）と `textEn`（説明文、1行1文）に入れます。見学中の右上の言語ボタンで日本語／Englishを切り替えられます。英語の文は「. 」（ピリオドと空白）で区切られるので、「No. 11」のような略語は「Number 11」と書きます
- `routes`（任意）は見学コースの一覧です。形式は `"routes": [{ "id": "R1", "name": "短縮コース", "spots": ["S01", "S03", "S06"] }]` で、`spots` にスポットの `id` を回る順に並べます。`routes` が無い台本は、全スポットを番号順に回る1コースとして動きます
- `map` は省略できます（その場合はスポットの緯度経度から簡易マップを描きます）
- `x` `y` は構内図画像の上での画素位置です
- `image` はスポットの写真（データURL）で、説明中の背景に表示されます
- 暗号化ファイルの形式は `{"format":"tour-enc-v1", ...}` です（PBKDF2-SHA256 で鍵を作り、AES-GCM 256bit で暗号化。ブラウザ標準の Web Crypto API を使用）

## 7. 本体を更新したとき

`sw.js` の先頭にある `CACHE = 'tour-guide-vN'` の番号（N）を上げてからアップロードします。
iPadでネットにつないだ状態でアプリを開くと、新しい版を裏で取り込み、数秒後に自動で切り替わります（説明の再生中や入力中は、終わってから「開き直す」と切り替わります）。

**画面が古いままのとき：** GitHubの `sw.js` の番号が上がっているか確認し、パソコンのブラウザなら「強制再読み込み」（Macは Command＋Shift＋R、Windowsは Ctrl＋Shift＋R）を行います。iPadなら、アプリを完全に終了して開き直し、10秒ほど待ってからもう一度開き直してください。

## 8. 注意点

- 位置情報・オフライン保存・暗号化はHTTPSでのみ動きます（GitHub PagesはHTTPSです）。`file://` で直接開いても動きません
- GPSが使えるのはCellularモデルのiPadです。Wi-Fiモデルは、Wi-Fiが無い場所では位置が取れません
- 画面の自動消灯防止（Wake Lock）は、iPadOSのバージョンによっては効きません。その場合は 設定 → 画面表示と明るさ → 自動ロック を「なし」にしてください
- 写真や構内図を入れるとファイルが大きくなります（アプリ側で縮小しています）
- サンプル台本の座標・内容は架空のものです
